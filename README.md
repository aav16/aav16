## 🚀 Featured Project

### [BookVision — Automatic book identification from cover photos](https://github.com/aav16/TFM_BookVision_SistemaInteligenteCatalogacionLibros)
*Master's Thesis (MSc in Data Science, UCJC)*

End-to-end pipeline that identifies a book from a photo of its cover: image preprocessing with OpenCV,
OCR, title/author/ISBN extraction, CNN-based visual similarity (MobileNetV3), fuzzy matching and
metadata lookup via Google Books / Open Library. Evaluated on **253 real photographs** with an
empirically calibrated decision threshold.
